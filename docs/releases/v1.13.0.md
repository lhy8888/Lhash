# LHash v1.13.0 · 熟悉的文件校验体验，现在来到 Mac

**拖入文件，计算摘要，轻松核对。**

LHash 是一款专注于本地文件校验的轻巧工具。检查下载的安装包、核对系统镜像，或为一整批文件保存校验记录，都可以在一个清晰的窗口中完成。文件留在你的电脑上，计算过程无需注册账号，也无需上传文件。

## 本次亮点：全新 Mac 图形界面

为 Apple Silicon M 系列 Mac 带来原生桌面体验，沿用 Windows 版熟悉的操作布局：**打开、打开文件夹、验证、全部复制、导出、设置**。从 Finder 拖入文件或文件夹，即可开始计算；每个文件的状态、进度和结果一目了然。

- **18 种算法，跨平台一致。** 默认提供 SHA-256、SHA-512 和 SHA3-256，也可按需选择 BLAKE3、BLAKE2、SHAKE、XXH3 等算法。
- **一次处理多个文件。** 支持文件夹批量计算，随时查看任务进度、停止任务，保留已经完成的结果。
- **核对结果更直接。** 粘贴预期校验值查找匹配，点击摘要复制，或一键复制全部结果。
- **结果随手保存。** 导出文本校验记录，方便归档、分享和后续比较。
- **用起来更顺手。** 原生 Mac 控件与快捷键，中文、英文界面，记住算法与大小写偏好。

Windows x64、Windows ARM64 和 macOS 命令行工具继续同步提供。喜欢图形界面，打开即用；习惯终端，也可以通过命令行批量处理并输出 JSON。

## 选择你的版本

在本页 **Assets** 中下载对应文件：

| 你的设备 | 下载文件 |
| --- | --- |
| Windows x64 电脑 | `LHash-windows-x64-<commit>.zip` |
| Windows ARM64 电脑 | `LHash-windows-arm64-<commit>.zip` |
| Apple Silicon Mac · 图形界面 | `LHash-macos-arm64-app-<commit>.zip` |
| Apple Silicon Mac · 命令行 | `LHash-macos-arm64-cli-<commit>.tar.gz` |

Mac 图形界面支持 **macOS 14 及以上的 M 系列 Mac**。

Windows 解压后运行 `LHash.exe`。Mac 图形界面解压后，将 `LHash.app` 拷贝到“应用程序”并打开。首次安装帮助见 [Mac 使用指南](https://github.com/lhy8888/Lhash/blob/v1.13.0/docs/MACOS_GUI.md#get-the-app)。

**打开或拖入文件 → 查看校验结果 → 核对、复制或导出。**
