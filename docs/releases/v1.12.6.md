# LHash v1.12.6

本次更新升级至 OpenSSL 3.5.9，修复 Windows 结果文字叠画、文件信息与摘要错序的问题，并提供与 Windows 相同 18 种算法的 macOS Apple Silicon 命令行版本。

## 下载

| 平台 | 发布文件 | 界面 |
| --- | --- | --- |
| Windows x64 | `LHash-windows-x64-<commit>.zip` | MFC 图形界面 |
| Windows ARM64 | `LHash-windows-arm64-<commit>.zip` | 原生 ARM64 MFC 图形界面 |
| macOS Apple Silicon | `LHash-macos-arm64-cli-<commit>.tar.gz` | `lhash` 命令行 |

macOS 使用通用 arm64 构建，面向 M 系列 Mac，不提供 Intel 版本或 macOS 图形界面。macOS 包目前未签名、未公证。

发布资产附带 `SHA256SUMS.txt`、`RELEASE_MANIFEST.txt`、`LHash-release.cyclonedx.json` 和 GitHub 构建证明。校验方法见 [发布验证说明](https://github.com/lhy8888/Lhash/blob/v1.12.6/docs/RELEASE_VERIFICATION.md)。

## 主要更新

- 修复增量输出插入旧选区的问题，消除结果文字叠画及文件信息与摘要错序；追加结果时保留用户选区。
- 重复输入使用独立任务身份；取消、未执行与异常中止有明确终态，已完成结果保留。
- 目录扫描移至后台；任务查找、汇总与结果追加减少重复处理，耗时统计改用单调时钟。
- 升级原样 OpenSSL 源码至 3.5.9，Windows x64/ARM64 与 macOS arm64 默认启用上游汇编优化，保留 portable 构建选项。
- macOS CLI 接入完整 18 算法注册表，支持 `--all`、算法列表及 JSON 输出；标准输出写入失败返回非零退出码。
- 补充文件读取、任务生命周期和发布资产一致性检查；修复 Windows 关闭过程中的清理顺序及消息冲突问题。

Windows x64 与原生 ARM64 的 GUI 回归覆盖每平台 18 个场景，包括读取中设置选区、后续追加、128 个不同文件的结果顺序与摘要对应。核心回归覆盖优化及 portable 构建，另有 Linux/macOS sanitizer 和 CodeQL 检查；这不代表所有显示配置均做过像素比对。

## English

This release updates the pristine OpenSSL dependency to 3.5.9 and fixes the Windows result-display regression: incremental text could be inserted at an old selection, causing overlapping glyphs and incorrect metadata/digest order. Results now append at the actual end while preserving the selection.

It also improves duplicate-task identity, cancellation outcomes, background folder scanning, incremental UI updates, elapsed-time measurement and shutdown cleanup. OpenSSL uses upstream assembly by default on all supported architectures, with an explicit portable build option.

The macOS Apple Silicon CLI now ships alongside the Windows x64 and ARM64 applications and exposes the same 18 algorithms. It supports algorithm selection, `--all`, algorithm listing and JSON output; output failures return a nonzero exit code. The macOS package is unsigned and not notarized; no Intel Mac build or macOS GUI is included.

Download the package matching your platform and use the published checksums, manifest and SBOM to verify it. See the [README](https://github.com/lhy8888/Lhash/blob/v1.12.6/README.md) for usage and [changelog](https://github.com/lhy8888/Lhash/blob/v1.12.6/CHANGELOG.md) for details.
